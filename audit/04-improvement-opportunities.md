## Explicitly rejected / kept as-is (for the record)

- **Implement the App-Group/WidgetKit bridge for v1** — rejected (see OPP-03/OPP-09).
- **Unfreeze OAuth token refresh (ADR-012 §3)** — rejected for v1; the freeze stands for a
  *stronger* reason than the ADR records (refresh-token rotation could strand the user's own
  Claude Code login — SEC-08). Do the S-effort copy fix instead (expired-at-launch state says
  "run `claude` to refresh your token" rather than funneling to the cookie WebView) and add
  the rotation hazard to ADR-012's Why.
- **Pivot to API-key providers now** — rejected; unchanged from ADR-012 §4 (retained fallback).
- **Monorepo restructure** — rejected; the layout earns its keep (ORG-09/ORG-10).
- **Sparkle / notarized DMG for v1** — rejected; remains the documented future option
  (ADR-006), now with the concrete trigger: it is the same decision-bundle as WidgetKit + iOS.
