### Changes in v1.1.0

- Choose **Claude** or **Codex** in Settings. The menu bar, popover and desktop widget show the selected subscription's reported consumption and reset times.
- Start Claude sign-in from Houdini through the installed official Claude Code client and your browser. Existing credentials and saved-session fallback remain readable; new sign-ins no longer use the embedded Google window.
- Connect Codex through its official client. Houdini uses a separate local authentication scope and requires Keychain storage. Only quota windows actually returned by Codex are shown.
- Switching subscriptions clears previous values and ignores late responses from the former subscription.
- Desktop widget resize limits now remain in effect after its SwiftUI content is installed.

### Requirements and boundaries

Claude connections require the official Claude Code client and an eligible subscription. Codex connections require the official Codex CLI **0.150.x**. Missing or unsupported clients receive guidance in Settings. The app does not install either client automatically.

Codex windows are the limits returned by Codex, not a universal allowance for every ChatGPT feature. The bundled data-layer CLI retains its existing Claude commands; provider selection is in the native app.

Claude usage reads retain the private integration and its existing risk disclosure. Houdini does not refresh or log out the user's Claude Code credential. See [the privacy page](https://houdini.salomao.org/privacy).

### Validation

Codex browser login, live quota reads, switching and session recovery after app restart were observed. Native keyboard/focus checks passed, as did the desktop widget's display-dependent smoke test. Claude's official browser handoff was observed; the owner approved release without repeating a successful live Claude account/usage round trip. Automated credential-discovery and login-process tests remain part of the verification.
